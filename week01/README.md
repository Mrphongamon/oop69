# OOP Week 01

รายวิชา: 31901-2006 การพัฒนาซอฟต์แวร์เชิงวัตถุ

## วัตถุประสงค์
ศึกษาและเตรียมสภาพแวดล้อมสำหรับพัฒนาโปรแกรม Python

## เครื่องมือ
- Python 3.13
- Visual Studio Code
- Python Virtual Environment (.venv)

## ไฟล์โปรแกรม
main.py - โปรแกรมแสดงข้อมูลรายวิชาและเป้าหมายการเรียนรู้

## วิธีรันโปรแกรม
1. เปิดโฟลเดอร์ week01 ด้วย VS Code
2. สร้าง .venv หากยังไม่มี
3. เลือก Python Interpreter จาก .venv
4. เปิด Terminal และรันคำสั่ง

.\.venv\Scripts\python.exe main.py

## ผลการทดสอบ
โปรแกรมทำงานได้ถูกต้องและแสดงผลครบ 4 บรรทัด
